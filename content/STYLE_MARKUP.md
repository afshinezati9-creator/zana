# پرامپت و راهنمای استایل اسلاید زانا

این فایل را به هر مدل هوش مصنوعی بده تا اسلایدهای ابزار/مشکل را با همین تگ‌ها بنویسد.

---

## قالب کلی هر اسلاید

```
SLIDE 1 | عنوان اسلاید
متن بدنه اینجا. می‌تواند چند پاراگراف باشد.

SLIDE 2 | عنوان بعدی
متن...
```

- هر اسلاید **باید** با خط `SLIDE N | عنوان` شروع شود.
- شماره N ترتیبی است (۱، ۲، ۳ …).
- تعداد اسلایدها آزاد است (تا حدود ۱۰۰).
- برای اسلاید منابع علمی آخر، عنوان را «منابع علمی» بگذار و بدنه را داخل `[ltr]...[/ltr]` بنویس.

## ساختار و فهرست

| تگ | کار |
|----|-----|
| `[hr]` | خط افقی جداکننده |
| `[sep]عنوان بخش[/sep]` | جداکننده با عنوان |
| `[key]کلید \| مقدار[/key]` | جفت کلید–مقدار |
| `[num]۱ \| متن کنار شماره[/num]` | شماره + متن |
| `[steps]...[/steps]` | مراحل (هر خط یک قدم) |
| `[ol]...[/ol]` | فهرست شماره‌ای |
| `[list]...[/list]` | فهرست گلوله‌ای |
| `[check]مورد تیک‌دار[/check]` | آیتم چک‌لیست |

مثال steps:
```
[steps]
تعریف ترس با جزئیات حسی
سه راه پیشگیری بنویس
اگر اتفاق افتاد، ترمیم را مشخص کن
[/steps]
```

## نمونهٔ کامل یک اسلاید

```
SLIDE 3 | مثال واقعی خودمونی
[h2]صبح یک سه‌شنبه در تهران[/h2]
رضا ساعت ۷ بیدار می‌شود و قبل از اینکه چشم‌هایش کامل باز شود، گوشی را چک می‌کند.

[tip]اگر این صحنه برایت آشناست، احتمالاً با الگوی «فرسودگی شبکه‌های اجتماعی» هم‌پوشانی داری.
[/tip]

[warn]اگر بیش از دو هفته است که بدون شبکه نمی‌توانی روز را شروع کنی، سطح هشدار است.
[/warn]

[quote]تو ماشین نیستی. تو انسان هستی که نیاز به مرز و استراحت دارد.
[/quote]
```

## قوانین محتوا (غیرقابل مذاکره)

1. هیچ‌وقت نگو «تو این اختلال را داری».
2. دارو، دوز یا پروتکل درمانی تجویز نکن.
3. در سطح بحران صریحاً بگو خوددرمانی نکن و به کمک فوری ارجاع بده.
4. منابع واقعی با DOI یا URL معتبر؛ منبع جعلی نساز.
5. در اسلاید منابع از `[ltr]` استفاده کن.
6. برای مخاطب ایرانی مثال بزن («صبح تهران»، نه «صبح توکیو»).
7. از ** ستارهٔ مارک‌داون استفاده نکن؛ فقط تگ‌های بالا.

## فیلدهای فرم مدیریت

- **عنوان (فارسی):** نام نمایشی
- **نام فایل انگلیسی:** فقط `a-z`، عدد، `_` (مثل `job_burnout` یا `1001`)
- **دسته‌بندی:** از لیست ثابت انتخاب شود
- **زمان / توضیح کوتاه / متن اسلایدها:** آزاد

بعد از ذخیره، فایل JSON را در:
- ابزار → `content/units/methods/{id}.json`
- مشکل → `content/units/problems/{id}.json`

بگذار و یک‌بار `flutter clean && flutter run -d chrome` بزن.
