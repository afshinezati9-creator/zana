# انتشار زانا در کافه‌بازار

این چک‌لیست برای آماده‌سازی و آپلود نسخهٔ اندروید در **کافه‌بازار** است. قوانین دقیق را همیشه از پنل توسعه‌دهندگان و مستندات رسمی کافه‌بازار چک کنید؛ این فایل خلاصهٔ عملی برای پروژهٔ زانا است.

## قبل از ساخت APK

1. **Package name** ثابت بماند: `ir.zana.app` (اگر در `android/app/build.gradle` چیز دیگری است، با همان در پنل ثبت کنید).
2. **versionName / versionCode** را در `pubspec.yaml` بالا ببرید (مثلاً `1.0.0+1` → `1.0.1+2`).
3. **امضا (keystore)** را فقط روی سیستم خودتان نگه دارید؛ هرگز در GitHub عمومی نگذارید.
4. فایل `android/key.properties` از روی `key.properties.example` ساخته شود و در `.gitignore` بماند.

## ساخت APK انتشار

```bat
cd C:\Users\1\Desktop\zn
flutter pub get
flutter build apk --release
```

خروجی معمول:

`build\app\outputs\flutter-apk\app-release.apk`

برای App Bundle (در صورت نیاز فروشگاه):

```bat
flutter build appbundle --release
```

## محتوای الزامی در پنل کافه‌بازار

| مورد | پیشنهاد برای زانا |
|------|-------------------|
| عنوان | زانا · کتابخانه رشد و خودآگاهی |
| توضیح کوتاه | ابزارها و الگوهای خودآگاهی به زبان ساده — بدون تشخیص پزشکی |
| توضیح کامل | تأکید: آموزشی است، جایگزین روان‌شناس/پزشک نیست؛ آفلاین؛ رایگان |
| دسته | سبک زندگی / آموزش / سلامت (طبق دسته‌بندی فعلی بازار) |
| رده سنی | مناسب بزرگسال؛ اگر محتوای حساس دارید محدودیت سنی را رعایت کنید |
| اسکرین‌شات | خانه، مسیر، کتابخانه، یک اسلاید ابزار، یک اسلاید مشکل |
| آیکن | همان آیکن رسمی اپ |

## قوانین محتوایی مهم (خلاصه)

- **وعده درمان یا معجزه ندهید.** زانا تشخیص و درمان نیست.
- در توضیحات فروشگاه بنویسید: خودیاری آموزشی + ارجاع مسئولانه.
- محتوای بحران: ارجاع به کمک تخصصی/خطوط اضطراری؛ خوددرمانی بحران را تشویق نکنید.
- محتوای جنسی/اعتیاد: فقط در چارچوب آموزشی، محترمانه، بدون محتوای صریح غیرمجاز.
- **حریم خصوصی:** اعلام کنید دادهٔ شخصی به سرور نمی‌رود (مدل آفلاین فعلی).
- بدون تبلیغ گمراه‌کننده، بدون اجبار به خرید برای امکانات اصلی (نسخه رایگان کامل).
- حقوق معنوی محتوا و فونت‌ها را رعایت کنید (وزیرمتن و منابع ذکرشده).

## حریم خصوصی (متن نمونه برای فروشگاه)

> زانا به‌صورت آفلاین کار می‌کند. پیشرفت و نتیجهٔ مسیر فقط روی دستگاه شما ذخیره می‌شود. اطلاعات شخصی به سرور ارسال نمی‌شود. اپ رایگان است و اشتراک اجباری ندارد.

## بعد از آپلود

1. بررسی نسخه توسط کافه‌بازار ممکن است چند ساعت تا چند روز طول بکشد.
2. اگر رد شد، متن رد را بخوانید (معمولاً توضیحات گمراه‌کننده، رده سنی، یا مجوزها).
3. برای به‌روزرسانی بعدی فقط `versionCode` را افزایش دهید و APK جدید بفرستید.

## GitHub Actions

با push روی `main`، workflow می‌تواند APK بسازد. برای APK امضاشده، Secrets را در ریپو تنظیم کنید:

- `KEYSTORE_BASE64`
- `KEYSTORE_PASSWORD`
- `KEY_PASSWORD`
- `KEY_ALIAS`

بدون Secrets، artifact برای تست داخلی است؛ برای فروشگاه بهتر است APK را محلی با keystore خودتان بسازید.
