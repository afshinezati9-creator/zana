# تنظیم Secretهای GitHub Actions برای زانا

در مخزن GitHub به مسیر Settings → Secrets and variables → Actions بروید و این چهار Repository Secret را بسازید:

- `KEYSTORE_BASE64`: متن Base64 کامل فایل keystore (بدون کوتاه‌کردن یا شکستن محتوا)
- `KEYSTORE_PASSWORD`: رمز keystore
- `KEY_PASSWORD`: رمز کلید
- `KEY_ALIAS`: نام alias کلید (برای این پروژه معمولاً `zana`)

**هشدار امنیتی:** رمزهایی که قبلاً در نسخه عمومی این فایل قرار گرفته بودند افشا شده‌اند؛ آن‌ها را دوباره استفاده نکنید. پیش از انتشار واقعی، رمزهای keystore/key را با دسترسی به فایل keystore تغییر دهید یا یک کلید انتشار جدید بسازید و Secretها را با مقادیر جدید تنظیم کنید.

Package name: `ir.zana.app`

تا زمانی که هر چهار Secret تنظیم نشده باشند، اجرای CI معمولی فقط APK/AAB آزمایشی با کلید debug تولید می‌کند. این فایل‌ها برای انتشار در کافه‌بازار یا به‌روزرسانی نصب‌های قبلی مناسب نیستند. برای خروجی انتشار، اجرای دستی Workflow را با گزینه `production` انجام دهید.
